# Impeccable

## Design Context

### Users
Security operators, SOC analysts, and SREs running **ClawdStrike** — a runtime security
enforcement and EDR system for AI agents. They sit in front of this console for long sessions,
often in dark rooms, watching live agent telemetry, triaging policy violations, approving broker
capabilities, and auditing decisions. They are technical, fast, and unimpressed by chrome — they
want signal, density, and zero ambiguity about system state.

### Brand Personality
**"Forged Gold on Black Glass."** Elite, precise, authoritative, tactical, quietly cinematic.
Think a mission-control surface milled from obsidian with gold inlay — not a SaaS dashboard.
Three words: **forged, vigilant, exact.**

### Aesthetic Direction
- **Theme: dark.** Correct for an SRE/SOC observability + security console used in dim ops
  settings. This is a deliberate, context-derived choice, not a reflex.
- This is an **"OS inside a web app"** — a desktop shell with a real window manager
  (draggable/resizable windows via `@backbay/glia-desktop`), wallpaper, taskbar, and command
  palette. Preserve that OS feel; the redesign **adds a left navigation sidebar and a top header
  bar**, and **slims the taskbar**.
- Surfaces are near-black glass (`--void #000`, `--obsidian #0b0d10`, `--graphite #12151b`).
  Gold (`--gold #d6b15a`) is the **identity accent — used sparingly (the 10% in 60-30-10)** for
  active state, focus, and brand. Teal (`--teal #2fa7a0`) = live telemetry. Crimson
  (`--crimson #c23b3b`) = breach/violation. These are load-bearing semantics, not decoration.

### Established Design System — DO NOT "fix" these
This is a **live, shipping brand**, not a greenfield project. The following are intentional and
must be preserved for consistency with the rest of the app and the approved design handoff:
- **Fonts: Space Grotesk (display), Inter (body), JetBrains Mono (mono/labels).** Already wired
  through `src/index.css` and the glia-desktop theme in `src/App.tsx`. Keep them. (The generic
  "avoid Space Grotesk/Inter" guidance targets novel projects converging on defaults — it does
  not apply when respecting an established design system the user explicitly asked us to match.)
- **Glassmorphism** (backdrop-blur on windows, taskbar, sidebar) is the core "Black Glass"
  metaphor — purposeful, not decorative slop. Apply with restraint, not everywhere.
- The **Monitor sparkline** shows real violations/hour — meaningful data viz, not decoration.

### Hard rules for this work (impeccable absolute bans still apply)
- **No gradient text.** The design mock used a gradient-filled "clawdstrike" wordmark — render
  the **wordmark text in solid gold** instead. The forged-gold gradient is allowed **only** on the
  SVG **"C" logo glyph** (a graphic, not text).
- **No decorative left/right border stripes** on cards/list items/alerts. The sidebar's active-nav
  indicator (a 2px gold bar) is a **functional state affordance** on a nav item, not a decorative
  card stripe — that is acceptable and conventional (VS Code / Linear style). Do not add stripes
  anywhere else.
- Use tokens from `src/index.css` (`--gold`, `--teal`, `--crimson`, `--void`, `--obsidian`,
  `--graphite`, `--slate`, `--text`, `--muted`, radii). Do not hard-code new hex values that
  duplicate existing tokens.

### Design Principles
1. **Signal over chrome.** Every pixel earns its place; state (live/violation/active) is always
   unambiguous and color-coded by the semantic palette.
2. **Forged, not flat.** Depth comes from inset gold edges, subtle blooms, and engraved marks —
   restrained, never glowy or neon.
3. **Gold is rare.** Reserve gold for identity, active, and focus. Most of the surface is calm
   near-black with muted-slate text.
4. **OS-native muscle memory.** Sidebar = launcher/dock, header = breadcrumb + system pulse,
   taskbar = running apps + clock. Keyboard-first (⌘K). Don't fight the window manager.
5. **Production-grade restraint.** No AI-slop tells. Tasteful motion on state changes only;
   no bounce, no gratuitous micro-interactions.
