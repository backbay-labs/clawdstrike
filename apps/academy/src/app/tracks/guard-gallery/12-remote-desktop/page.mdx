# Remote Desktop Side Channel Guard

Remote desktop sessions expose side channels that can leak data even when the primary
session is locked down. The RemoteDesktopSideChannelGuard individually controls 6
channels to prevent data exfiltration and unauthorized access.

## The Threat

Even with the Computer Use Guard controlling which CUA actions are allowed, side
channels offer alternative data paths:

- **Clipboard** -- Copy sensitive data from the remote session to the local machine
- **File transfer** -- Download files from the remote session
- **Session sharing** -- Grant unauthorized users access to the session
- **Drive mapping** -- Mount the local filesystem inside the remote session
- **Audio** -- Capture audio streams (voice data, notifications)
- **Printing** -- Print documents from the remote session to local printers

An agent could exfiltrate data via clipboard copy, transfer files to the local machine,
share sessions with unauthorized users, or use drive mapping to access the local
filesystem -- all without triggering the Computer Use Guard.

## How It Works

The guard matches on 6 specific `remote.*` action types, each with its own
enabled/disabled toggle:

1. **`remote.clipboard`** -- Clipboard read/write
2. **`remote.file_transfer`** -- File transfer, with optional `max_transfer_size_bytes` limit
3. **`remote.session_share`** -- Sharing the session with others
4. **`remote.audio`** -- Audio channels
5. **`remote.drive_mapping`** -- Mounting local drives in the remote session
6. **`remote.printing`** -- Printing from the remote session

Any `remote.*` type NOT in these 6 known channels is **denied** (fail-closed for unknown
channels). The guard accepts both snake_case and camelCase for the transfer size field.

The `is_remote_side_channel_candidate()` function filters which actions this guard
evaluates -- session management actions (`remote.session.connect`, `remote.session.disconnect`,
`remote.session.reconnect`) are handled by the Computer Use Guard, not this one.

## Configuration

```yaml
guards:
  remote_desktop_side_channel:
    enabled: true
    clipboard_enabled: false
    file_transfer_enabled: true
    max_transfer_size_bytes: 10485760  # 10MB
    session_share_enabled: false
    audio_enabled: true
    drive_mapping_enabled: false
    printing_enabled: true
```

- **`clipboard_enabled`** -- Allow clipboard read/write (default: false)
- **`file_transfer_enabled`** -- Allow file transfers (default: true)
- **`max_transfer_size_bytes`** -- Maximum file transfer size in bytes (default: 10MB)
- **`session_share_enabled`** -- Allow session sharing (default: false)
- **`audio_enabled`** -- Allow audio channels (default: true)
- **`drive_mapping_enabled`** -- Allow drive mapping (default: false)
- **`printing_enabled`** -- Allow printing (default: true)
