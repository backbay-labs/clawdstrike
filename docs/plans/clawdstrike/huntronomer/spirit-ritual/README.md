# Spirit Ritual Rewrite

> **Status:** Proposed | **Date:** 2026-03-08
> **Audience:** Product, design, desktop, motion, and 3D-scene implementers
> **Scope:** Replace the current operational spirit configuration flow with a Baia-inspired artistic creation ritual

This initiative exists because the current `Configure Spirit` flow is structurally correct but experientially wrong.

It behaves like a compact operational settings sheet.
The user direction is much stronger:

> spirit creation should feel like an artistic act, a release ritual, and a living embodiment of curiosity and creativity

That means the spirit system needs a second, dedicated initiative:

- [Spirit Ritual Roadmap](./roadmap.md)
- [Spirit Ritual Swarm Plan](./swarm-plan.md)

This rewrite should borrow Baia's actual creation grammar:

- multimodal input
- suggestion chips and interpretive feedback
- live artifact manifestation
- atmospheric controls
- explicit release into the world

It should **not** borrow Baia's occult framing or collectible logic.

The north star is:

> a hunt is created instantly, but spirit shaping feels like entering a chamber, gathering intent, manifesting a living form, and releasing it into the workspace
