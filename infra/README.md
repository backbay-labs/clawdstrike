# Infra

Infrastructure and packaging assets that support build, release, and deployment workflows.

Current:

1. `infra/packaging/HomebrewFormula/` - Homebrew formula for `hush`.
2. `infra/deploy/` - deployment manifests and runtime policy assets.
3. `infra/docker/` - container build definitions and compose files.
4. `infra/vendor/` - three preserved path-deps (`nono` first-party fork,
   `async-nats` patch crate, `rustls-webpki` security backport). The full
   offline-build mirror is regenerated by CI at run time via `cargo vendor`;
   it is NOT committed (see `.github/workflows/ci.yml` `offline` job and
   `.cargo/config.toml`).
