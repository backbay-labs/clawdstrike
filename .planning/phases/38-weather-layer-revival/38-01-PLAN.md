```typescript
// effectiveWeatherState is already computed — null when weather disabled
const effectiveWeatherState = useMemo(() => {
  if (!weatherState || !performanceProfile.enableWeather) return null;
  const budgetRank = { off: 0, reduced: 1, full: 2 } as const;
  const budget = budgetRank[performanceProfile.weatherBudget] < budgetRank[weatherState.budget]
    ? performanceProfile.weatherBudget : weatherState.budget;
  if (budget === "off") return null;
  if (budget === weatherState.budget) return weatherState;
  return {
    ...weatherState,
    budget,
    density: Math.min(weatherState.density, 0.06),
    labelOcclusionOpacity: Math.min(weatherState.labelOcclusionOpacity, 0.1),
  };
}, [performanceProfile.enableWeather, performanceProfile.weatherBudget, weatherState]);
```

Implementation requirements:

1. FOG MODULATION — Use `useThree` to get `scene`. In a `useEffect` keyed on
   `[weatherState.density, weatherState.tint, weatherState.style]`, mutate `scene.fog`:
   - If `scene.fog instanceof THREE.FogExp2`: add `weatherState.density * 0.006` to
     its `.density` (base is 0.0008; weather adds up to 0.00072 at density=0.12).
   - On unmount (cleanup), restore original fog density stored in a ref.
   - Do NOT replace the fog object — only mutate the density property.
   - Cap the fog delta at +0.0007 max regardless of density value.

2. AMBIENT TINT LIGHT — Render a `<pointLight>` at position [0, 60, 0] using
   `weatherState.tint` as color. Intensity = `weatherState.density * 3.5` (max ~0.42
   at density=0.12, zero at density=0). Set `distance={200}`, `decay={2}`.
   This adds the station-themed color cast without blowing out the existing lighting.

3. ATMOSPHERIC PARTICLES — Render `<Sparkles>` from @react-three/drei:
   - count = budget==="full" ? Math.round(weatherState.density * 600) : Math.round(weatherState.density * 280)
     (at density=0.12 full: 72 sparkles; reduced: 34 sparkles — never exceeds 80)
   - size = 0.8
   - speed = 0.04 + weatherState.phaseOffset * 0.02
   - opacity = weatherState.density * 1.8 (capped at 0.22)
   - color = weatherState.tint
   - scale = [160, 80, 160]  (wide, flat atmospheric spread)
   - Do not render Sparkles if count === 0.

All three elements are returned from a single fragment. No useFrame loop — the fog
effect uses useEffect and Sparkles handles its own animation.
