**SpeedIndicator.tsx** — Vertical speed bar (HUD-01):
- Outer container: absolute, left:16px, bottom:80px, width:12px, height:120px
- Background track: full height, bg "#1a2035", rounded-sm, border 1px solid #202531
- Fill bar: absolute bottom, same width, height set via ref. Background color set via ref based on speedTier
- Numeric readout below bar: textContent set via ref. Format: `${Math.round(currentSpeed)}` + small "u/s" label
- Boost cooldown indicator: when boostOnCooldown, show a small pulsing dot above the bar (CSS animation, visibility toggled via ref)
- `useEffect` on mount: starts a `requestAnimationFrame` loop that:
  1. Reads `useObservatoryStore.getState().flightState` (zero subscriptions)
  2. Reads `DEFAULT_FLIGHT_CONFIG` for cruiseSpeed, boostMultiplier, dockSpeed
  3. Computes `fillPercent = currentSpeed / activeSpeedTierCap` where activeSpeedTierCap = cruiseSpeed for cruise, cruiseSpeed*boostMultiplier for boost, dockSpeed for dock
  4. Sets `fillRef.current.style.height = ${Math.min(100, fillPercent * 100)}%`
  5. Sets `fillRef.current.style.backgroundColor = SPEED_TIER_COLORS[flightState.speedTier]`
  6. Sets `readoutRef.current.textContent = ${Math.round(currentSpeed)}`
  7. Calls `requestAnimationFrame(loop)` to continue
  8. Returns cleanup that cancels the rAF via `cancelAnimationFrame`
- CRITICAL: No useState, no useSelector, no setState anywhere in the rAF loop
- data-testid="hud-speed-indicator" on outer container

**HeadingCompass.tsx** — Horizontal compass strip (HUD-02):
- Outer container: absolute, top:16px, left:50%, transform:translateX(-50%), width:400px, height:28px, overflow:hidden
- Subtle bg "rgba(10,13,20,0.7)", border-bottom 1px solid #202531, backdrop-blur-sm
- Inner strip: width:1200px, position:absolute, will-change:transform
- Inner strip contents (rendered once, never re-mounted):
  - Cardinal markers at 0deg=N, 90deg=E, 180deg=S, 270deg=W — positioned as absolute elements at pixel offsets computed from their degree value: `pixelX = (degree / 360) * 1200`
  - Each cardinal: white text, 10px font, centered
  - Tick marks at every 30deg (12 total), 4px tall lines in #202531
  - Station labels: for each HUNT_STATION_PLACEMENTS, compute angleDeg (already in the placement data), create a label element at the corresponding pixel offset. Color: STATION_COLORS_HEX[stationId]. Text: HUNT_STATION_LABELS[stationId], font-size 8px
  - The inner strip repeats 3x (0-1200, 1200-2400, 2400-3600) for seamless wrapping
- `useEffect` on mount: starts a `requestAnimationFrame` loop that:
  1. Reads `useObservatoryStore.getState().flightState.quaternion`
  2. Extracts yaw from quaternion: create a THREE.Euler().setFromQuaternion(new THREE.Quaternion(q[0],q[1],q[2],q[3]), 'YXZ'). yawRad = euler.y. yawDeg = (-yawRad * 180 / Math.PI + 360) % 360
  3. Pre-allocate the Quaternion and Euler objects OUTSIDE the rAF loop (module-level or useRef) — no `new` inside the loop
  4. Computes `translateX = -(yawDeg / 360) * 1200 - 400 + 1200` (centers the window on current heading, offset by half visible width, shifted into middle repeat for wrapping)
  5. Sets `innerRef.current.style.transform = translateX(${translateX}px)`
  6. Calls `requestAnimationFrame(loop)` to continue
- Center indicator: a fixed triangle/line at the center bottom of the compass window (not on the inner strip), indicating current heading. CSS border triangle, 6px, color #e0e6ef
- data-testid="hud-heading-compass" on outer container
