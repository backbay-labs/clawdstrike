**useHudProjection.ts** — Projection logic hook:

Export interface `HudStationProjection`:
```typescript
export interface HudStationProjection {
  stationId: HuntStationId;
  label: string;
  colorHex: string;
  /** Screen-space X in pixels (0 = left edge) */
  screenX: number;
  /** Screen-space Y in pixels (0 = top edge) */
  screenY: number;
  /** World-space distance from ship in units */
  distance: number;
  /** True when the station is behind the camera or outside frustum */
  isOffScreen: boolean;
  /** Edge-clamped X for off-screen arrow placement */
  edgeX: number;
  /** Edge-clamped Y for off-screen arrow placement */
  edgeY: number;
  /** Rotation in radians for off-screen arrow pointing toward station */
  arrowRotation: number;
  /** Distance fade opacity: 0 at 500+ units, 1.0 at 100 units */
  distanceOpacity: number;
  /** Bracket size in px: clamp(800 / distance, 24, 80) */
  bracketSize: number;
  /** Whether this station is the selected/mission target */
  isSelected: boolean;
  /** Whether the ship is docked at this station */
  isDocked: boolean;
}
```

Export `useHudProjection(containerRef: RefObject<HTMLDivElement | null>)`:
- Returns `{ projectionsRef: RefObject<HudStationProjection[]> }`
- On mount: starts a requestAnimationFrame loop.
- Pre-allocate module-level scratch objects: `_projVec = new THREE.Vector3()`, `_viewProjectionMatrix = new THREE.Matrix4()`
- Each frame in the rAF loop:
  1. Get container dimensions: `const rect = containerRef.current?.getBoundingClientRect()` — cache rect, only re-read if null or every 60 frames (resize detection without ResizeObserver overhead)
  2. Read `hudCameraRef.current` for projectionMatrix and matrixWorldInverse
  3. Compute viewProjection: `_viewProjectionMatrix.copy(hudCameraRef.current.projectionMatrix).multiply(hudCameraRef.current.matrixWorldInverse)`
  4. Read `useObservatoryStore.getState()` for flightState.position, selectedStationId, dockingState, mission
  5. Get selectedStationId from store, also check mission target: `getCurrentObservatoryMissionObjective(mission)?.stationId`
  6. For each station in HUNT_STATION_ORDER:
     - Set `_projVec` to station world position from OBSERVATORY_STATION_POSITIONS
     - Apply viewProjection: `_projVec.applyMatrix4(_viewProjectionMatrix)`
     - NDC z check: `isBehind = _projVec.z > 1` (behind camera)
     - Convert NDC to screen: `screenX = ((_projVec.x + 1) / 2) * width`, `screenY = ((1 - _projVec.y) / 2) * height`
     - If behind camera: flip coords around center: `screenX = width - screenX`, `screenY = height - screenY`
     - `isOffScreen = isBehind || screenX < 0 || screenX > width || screenY < 0 || screenY > height`
     - Edge clamp with 40px margin: clamp screenX to [40, width-40], screenY to [40, height-40]
     - arrowRotation: `Math.atan2(centeredY, centeredX)` where centered = screen center minus clamped position
     - Distance: `Math.hypot(pos[0]-ship[0], pos[1]-ship[1], pos[2]-ship[2])` using flightState.position and OBSERVATORY_STATION_POSITIONS
     - distanceOpacity: `Math.max(0, Math.min(1, (500 - distance) / 400))`
     - bracketSize: `Math.max(24, Math.min(80, 800 / Math.max(1, distance)))`
     - isSelected: stationId === selectedStationId || stationId === missionTargetStationId
     - isDocked: dockingState.zone === "dock" && dockingState.stationId === stationId
  7. Write results into `projectionsRef.current` (reuse array, no allocation — assign to existing slots or splice)
  8. Call the `onProjectionsReady` callback (passed during setup) which TargetBrackets and OffScreenArrows subscribe to
- Actually, simpler pattern: just update projectionsRef.current in place. TargetBrackets/OffScreenArrows each run their own rAF that reads projectionsRef.current. OR — single rAF drives everything by calling passed-in updater callbacks.
- Best approach: useHudProjection runs the single rAF loop and calls `updateCallbackRef.current(projections)` each frame. Each consumer (TargetBrackets, OffScreenArrows) registers via `registerHudConsumer(callback)`. Keep it simple: just expose projectionsRef and let consumers read it in their own rAF.
- SIMPLEST: useHudProjection updates projectionsRef.current each frame. Export it. TargetBrackets and OffScreenArrows each read projectionsRef.current in their own rAF loops.
- Cleanup: cancelAnimationFrame on unmount.
- ZERO useState, ZERO useSelector.

     - Distance readout textContent: `${Math.round(distance)}m`
     - Distance readout opacity: distanceOpacity
  3. requestAnimationFrame(loop)
