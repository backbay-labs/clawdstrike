**1. mulberry32 seeded RNG** (inline — no npm dep):
```typescript
export function mulberry32(seed: number): () => number {
  let s = seed;
  return () => {
    s |= 0; s = s + 0x6D2B79F5 | 0;
    let t = Math.imul(s ^ (s >>> 15), 1 | s);
    t = t + Math.imul(t ^ (t >>> 7), 61 | t) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}
```

**2. StationBuilding component** (WLD-02):
- Props: `{ seed: number; position: [number, number, number] }`
- Use `useMemo` to generate building dimensions from mulberry32(seed)
- Generate 4–6 buildings scattered in a ring at radius 1.4–2.2 from `position`
- Building offsets use `Math.cos/sin` spiral: `angle = (i / count) * Math.PI * 2 + seed * 0.01`
- Each building: main `<RoundedBox args={[width, height, width]} radius={0.04} smoothness={2}>` with `meshStandardMaterial color="#1a1f2e" emissive="#0a0e1a" roughness={0.8}`
- Add emissive antenna on top of each: thin cylinder `args={[0.02, 0.02, 0.5, 6]}` at `colorHex` color with `emissiveIntensity={0.5} toneMapped={false}` (picks up bloom)
- Keep buildings within a max radius of 2.2 from station center — do NOT overlap the hero prop zone (radius < 0.8)

**3. DistrictGround component** (WLD-03):
- Props: `{ position: [number, number, number]; colorHex: string }`
- Flat `<planeGeometry args={[10, 10, 1, 1]} />` rotated `[-Math.PI / 2, 0, 0]`, offset Y by -0.05 from position Y
- `meshStandardMaterial map={texture} color={colorHex} roughness={0.92} emissive={colorHex} emissiveIntensity={0.04}`
- Load texture with `useTexture('/textures/grid-floor.png', (t) => { t.wrapS = t.wrapT = THREE.RepeatWrapping; t.repeat.set(6, 6); })`
- Wrap in `<Suspense fallback={null}>` to avoid blocking if texture missing

**4. DistrictEnvProps component** (WLD-04):
- Props: `{ position: [number, number, number]; colorHex: string; seed: number }`
- Renders 2 crate boxes + 1 cable run per station
- Crates: `<mesh>` with `<boxGeometry args={[0.22, 0.22, 0.22]} />`, stacked/clustered at ~1.0 unit from position, using rng for offset
- Cable run: `<CatmullRomLine>` from drei with 3 control points weaving between the crate cluster at Y=0, color=colorHex, lineWidth={0.8}, transparent opacity={0.5}
- Import `CatmullRomLine` from `@react-three/drei`

Export all four: `export { mulberry32, StationBuilding, DistrictGround, DistrictEnvProps }`.
