R3F useFrame pattern for instanced NPC (from research):
```typescript
// NEVER setState inside useFrame — mutate refs only
useFrame(({ camera }, delta) => {
  // Patrol lerp
  const target = new THREE.Vector3(...waypoints[waypointIdxRef.current]);
  if (posRef.current.distanceTo(target) < 0.1) {
    waypointIdxRef.current = (waypointIdxRef.current + 1) % waypoints.length;
  } else {
    posRef.current.lerp(target, 0.5 * delta);
  }

  // Proximity reaction — use camera.position as player proxy
  const dist = posRef.current.distanceTo(camera.position);
  if (dist < PROXIMITY_THRESHOLD) {
    groupRef.current.lookAt(camera.position.x, posRef.current.y, camera.position.z);
    wavingRef.current = true;
  } else {
    wavingRef.current = false;
  }

  groupRef.current.position.copy(posRef.current);
});
```

**2. NpcInstance component** (one instance per NPC):
- Props: `{ waypointOffsets: [[number,number],[number,number],[number,number],[number,number]]; stationWorldPos: [number,number,number]; color: string }`
- Uses `useRef` for:
  - `posRef` — `THREE.Vector3` current world position
  - `groupRef` — ref to the `<Instance>` element (typed `THREE.InstancedMesh`)
  - `waypointIdxRef` — `number`, current waypoint index
  - `wavingRef` — `boolean` whether currently waving
  - `waveTimerRef` — `number` seconds elapsed while waving
  - `armOffsetRef` — `number` current arm wave Y-offset
- Waypoints derived via `useMemo`: resolve `waypointOffsets` into world-space `THREE.Vector3[]` by adding `stationWorldPos`
- `useFrame(({ camera }, delta) => { ... })`:
  1. Advance patrol: `posRef.current.lerp(waypoints[waypointIdxRef.current], 0.5 * delta)`; advance waypoint when within 0.15 units
  2. Proximity check: `dist = posRef.current.distanceTo(camera.position)`, threshold = 5.0
  3. If `dist < 5.0`: `wavingRef.current = true`, increment `waveTimerRef.current += delta`
  4. If `dist >= 5.0`: `wavingRef.current = false`, `waveTimerRef.current = 0`
  5. Apply position: `groupRef.current.position.copy(posRef.current)`
  6. Apply look-at when waving: `groupRef.current.lookAt(camera.position.x, posRef.current.y, camera.position.z)`
  7. Arm wave: update `armOffsetRef.current` = `wavingRef.current ? Math.sin(waveTimerRef.current * 4) * 0.15 : 0`
- Returns `<Instance ref={groupRef} position={[stationWorldPos[0]+waypointOffsets[0][0], 0, stationWorldPos[2]+waypointOffsets[0][1]]} />`
