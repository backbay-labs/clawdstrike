**useFlightInput.ts** — Input hook that produces FlightIntent each frame.

```typescript
import { useCallback, useEffect, useRef } from "react";
import { createEmptyFlightIntent, type FlightIntent, type FlightConfig, DEFAULT_FLIGHT_CONFIG } from "./flight-types";
import { getObservatoryNowMs } from "../../utils/observatory-time";
```

Interface:
```typescript
export interface UseFlightInputOptions {
  enabled: boolean;
  config?: FlightConfig;
}
export interface UseFlightInputResult {
  intentRef: React.RefObject<FlightIntent>;
  requestPointerLock: () => void;
}
```

Implementation details:
1. Track pressed keys in a `Set<string>` via `useRef` (NOT useState — avoids re-renders in the frame loop).
2. Keyboard mapping (per CONTEXT.md decisions):
   - W/ArrowUp = thrust +1, S/ArrowDown = thrust -1
   - A/ArrowLeft = strafe -1, D/ArrowRight = strafe +1
   - Space = vertical +1, ShiftLeft/ShiftRight = vertical -1
   - KeyE = interactTriggered (one-shot, consumed after read)
3. Mouse delta: Listen to `mousemove` events ONLY when `document.pointerLockElement` is the canvas. Accumulate `movementX` and `movementY` into the intentRef between frames. The flight loop reads and zeroes the deltas each frame.
4. Boost detection: Track `lastForwardPressMs` in a ref. On KeyW keydown (non-repeat), if `nowMs - lastForwardPressMs <= config.boostDoubleTapWindowMs` (default 300), set `boostTriggered = true` for one frame.
5. `requestPointerLock` — calls `document.body.requestPointerLock()` (the canvas element pointer lock). Used by SpaceFlightController on canvas click.
6. On `pointerlockchange`, update a ref tracking lock state.
7. When `enabled` becomes false, clear all pressed keys, zero all intent fields, and exit pointer lock if active.
8. All event listeners attach to `window` (keyboard) and `document` (mouse/pointerlock).
9. Return `intentRef` (a ref containing the current FlightIntent — read by useFlightLoop in useFrame) and `requestPointerLock`.

CRITICAL: intentRef.current is mutated directly each frame (no setState). The flight loop reads it via ref.

**useFlightLoop.ts** — Physics loop that updates ship position/orientation each frame.

```typescript
import { useFrame } from "@react-three/fiber";
import { useRef } from "react";
import * as THREE from "three";
import type { FlightConfig, FlightIntent, FlightState } from "./flight-types";
import { DEFAULT_FLIGHT_CONFIG, DEFAULT_FLIGHT_STATE } from "./flight-types";
```

Interface:
```typescript
export interface UseFlightLoopOptions {
  intentRef: React.RefObject<FlightIntent>;
  config?: FlightConfig;
  /** Ref to the ship Group — position/quaternion updated in-place */
  shipRef: React.RefObject<THREE.Group | null>;
  /** Callback to push flight state to store (throttled — not every frame) */
  onStateChange?: (state: FlightState) => void;
}
```

Implementation — `useFrame` callback:
1. Pre-allocate reusable objects OUTSIDE the hook (module-level):
   ```typescript
   const _quat = new THREE.Quaternion();
   const _euler = new THREE.Euler();
   const _forward = new THREE.Vector3();
   const _right = new THREE.Vector3();
   const _up = new THREE.Vector3(0, 1, 0);
   const _thrustVec = new THREE.Vector3();
   const _velocity = new THREE.Vector3();
   ```

2. Each frame (`useFrame((_, delta) => { ... })`):
   a. Clamp delta: `const dt = Math.min(delta, 1/20);`
   b. Read intentRef.current into local vars; zero mouseDelta after read.
   c. **Rotation (quaternion):** Apply yaw (around world Y) and pitch (around ship's local X) from mouse deltas:
      ```
      yawAngle = -intent.mouseDeltaX * config.yawSensitivity
      pitchAngle = -intent.mouseDeltaY * config.pitchSensitivity
      ```
      Build yaw quaternion from Euler(0, yawAngle, 0) and multiply onto ship quaternion.
      Build pitch quaternion from Euler(pitchAngle, 0, 0) in ship-local space and multiply.
      Apply to shipRef.current.quaternion.
   d. **Derive ship axes** from current quaternion:
      ```
      forward = new Vector3(0, 0, -1).applyQuaternion(shipQuat)
      right = new Vector3(1, 0, 0).applyQuaternion(shipQuat)
      up = new Vector3(0, 1, 0)  // world up for vertical thrust
      ```
   e. **Thrust:** Accumulate thrust vector:
      ```
      thrustVec = forward * intent.thrust + right * intent.strafe + up * intent.vertical
      thrustVec.normalize().multiplyScalar(config.thrustAcceleration * dt)
      velocity.add(thrustVec)
      ```
      Only apply if any intent axis is non-zero (avoid normalizing zero vector).
   f. **Damping:** `velocity.multiplyScalar(1 - config.dampingFactor * dt)` — per CONTEXT.md decision, dampingFactor=1.5.
   g. **Speed cap:** Clamp velocity magnitude to the active speed tier cap (cruiseSpeed for now — Plan 03 adds tier logic). If `velocity.length() > cap`, normalize and scale to cap.
   h. **Position update:** `shipRef.current.position.addScaledVector(velocity, dt)`.
   i. **Write to shipRef:** `shipRef.current.quaternion.copy(shipQuat)` (already set above).
   j. **State snapshot:** Every ~100ms (track lastSnapshotMs in a ref), call `onStateChange` with current FlightState extracted from ship position/velocity/quaternion. This keeps the store updated without per-frame setState.
   k. **Zero consumed fields:** Set `intentRef.current.mouseDeltaX = 0`, `mouseDeltaY = 0`, `boostTriggered = false`, `interactTriggered = false` after reading.

Export `useFlightLoop` as named export.

Implementation:
1. `const shipRef = useRef<THREE.Group>(null);`
2. Call `useFlightInput({ enabled: inputEnabled })` to get `intentRef` and `requestPointerLock`.
3. Call `useFlightLoop({ intentRef, shipRef, onStateChange })` to run physics each frame.
4. Write to `playerFocusRef.current` inside the flight loop's onStateChange callback, mapping FlightState to ObservatoryPlayerFocusState so FovController and other existing systems can read ship state:
   ```typescript
   playerFocusRef.current = {
     action: state.currentSpeed > 30 ? "sprint" : state.currentSpeed > 1 ? "walk" : null,
     airborne: false,
     facingRadians: 0, // Not used for flight — quaternion is truth
     moving: state.currentSpeed > 0.5,
     moveVector: [0, 0],
     position: [...state.position],
     sprinting: state.speedTier === "boost",
     stationId: state.nearestStationId,
   };
   ```
5. On canvas click (via `useThree` or an `onClick` prop), call `requestPointerLock()`.
6. Register the click handler on the `gl.domElement`:
   ```typescript
   const { gl } = useThree();
   useEffect(() => {
     if (!inputEnabled) return;
     const handler = () => requestPointerLock();
     gl.domElement.addEventListener("click", handler);
     return () => gl.domElement.removeEventListener("click", handler);
   }, [gl.domElement, inputEnabled, requestPointerLock]);
   ```

Render:
