**Part A: ShipMesh component**

Create `apps/workbench/src/features/observatory/character/ship/ShipMesh.tsx`:

Build a geometric low-poly ship from Three.js primitives, ~3 units long. The ship should match the station geometry style (procedural primitives, not GLB). Structure:

1. **Hull body** — ConeGeometry(0.5, 3, 6) rotated so the point faces -Z (forward). Color: white/gray base `#c8d0dc` with `metalness: 0.4, roughness: 0.5`.
2. **Cockpit canopy** — SphereGeometry(0.35, 8, 8) positioned at z=-0.8 (front area). Color: `#44aaff` with `emissiveIntensity: 0.6, metalness: 0.7`.
3. **Wing struts** — Two BoxGeometry(1.8, 0.06, 0.6) at y=0, x=+-0.7, z=0.3, slightly swept back. Color: `#a0aab8`, metalness: 0.5.
4. **Thruster nozzles** — 4x CylinderGeometry(0.1, 0.14, 0.3, 8) at positions matching SHIP_THRUSTER_LAYOUT.nozzlePositions. Color: `#ff8844`, emissive `#ff6622`, emissiveIntensity: 2.0, toneMapped: false (so bloom picks them up).

Props interface:
```typescript
export interface ShipMeshProps {
  /** Spirit accent color — tints hull panels */
  accentColor?: string;
  /** Scale multiplier (default 1) */
  scale?: number;
}
```

The component renders a `<group>` containing all primitives. If `accentColor` is provided, apply it as the emissive color on the wing struts at intensity 0.3 to subtly tint them with the bound spirit color.

Use `useMemo` for geometry creation (not inline JSX geometry) to avoid re-creation on re-render. Use `useFrame` for a subtle idle hover/bob animation (sinusoidal Y offset amplitude 0.05, speed 1.2).

Export `ShipMesh` as named export.
