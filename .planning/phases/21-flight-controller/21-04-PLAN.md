Create `apps/workbench/src/features/observatory/character/ship/ChaseCamera.tsx`:

```typescript
import { useRef } from "react";
import { useFrame, useThree } from "@react-three/fiber";
import * as THREE from "three";
```

Props:
```typescript
export interface ChaseCameraProps {
  /** Ref to the ship Group whose position/quaternion we follow */
  shipRef: React.RefObject<THREE.Group | null>;
  /** Chase offset in ship-local space [x, y, z] — default (0, 4, 14) = behind and above */
  offset?: [number, number, number];
  /** Lerp follow factor per frame (0-1) — lower = more lag. Default 0.07 per CONTEXT.md */
  followFactor?: number;
  /** Look-at forward offset — camera looks slightly ahead of ship center. Default 8 units */
  lookAheadDistance?: number;
}
```

Implementation:
1. Pre-allocate module-level vectors:
   ```typescript
   const _desiredPos = new THREE.Vector3();
   const _lookTarget = new THREE.Vector3();
   const _offset = new THREE.Vector3();
   const _shipForward = new THREE.Vector3();
   ```

2. `useFrame` callback:
   a. If `!shipRef.current`, return early.
   b. Compute desired camera position:
      - Get the offset vector `(0, 4, 14)` and rotate it by the ship's quaternion to get the world-space offset behind+above the ship:
        ```
        _offset.set(offset[0], offset[1], offset[2]);
        _offset.applyQuaternion(shipRef.current.quaternion);
        _desiredPos.copy(shipRef.current.position).add(_offset);
        ```
   c. Compute look-at target:
      - Ship forward direction from quaternion: `_shipForward.set(0, 0, -1).applyQuaternion(shipRef.current.quaternion)`
      - Look target = ship position + forward * lookAheadDistance:
        ```
        _lookTarget.copy(shipRef.current.position).addScaledVector(_shipForward, lookAheadDistance);
        ```
   d. Lerp camera position toward desired:
      ```
      const alpha = 1 - Math.exp(-followFactor * 60 * dt);  // frame-rate independent lerp
      camera.position.lerp(_desiredPos, alpha);
      ```
   e. Smoothly orient camera toward look target:
      ```
      camera.lookAt(_lookTarget);
      ```
   f. `camera.updateMatrixWorld()` to ensure child objects see the updated transform.

3. Access camera via `useThree`: `const { camera } = useThree();`

4. This component renders `null` — it only mutates the camera each frame.

5. IMPORTANT: The chase camera ONLY activates when the ship is in flight mode. In atlas mode, OrbitControls is `makeDefault` and manages the camera. The chase camera should NOT fight OrbitControls. The SpaceFlightController only mounts when `inputEnabled` is true (flow mode + character controller on), so ChaseCamera is only mounted inside SpaceFlightController.
