    **1. Extend ObservatoryState type** (types.ts):
    Add `discoveredStations: Set<HuntStationId>` field to `ObservatoryState` interface.

    **2. Extend observatory store** (observatory-store.ts):
    Add to initial state: `discoveredStations: new Set<HuntStationId>(["signal", "targets"])` — per CONTEXT.md, origin hub area + 2 nearest stations start discovered.
    Add action `discoverStation`:
    ```typescript
    discoverStation: (stationId: HuntStationId) =>
      set((state) => {
        if (state.discoveredStations.has(stationId)) return state;
        const next = new Set(state.discoveredStations);
        next.add(stationId);
        return { discoveredStations: next };
      }),
    ```

    **3. Rewrite StationLodWrapper** to add discovery gate + animation:

    Add a `discovered` prop check: read `discoveredStations` from store via `useObservatoryStore.getState()` inside `useFrame` (zero subscriptions in render loop).

    **Discovery gate logic:**
    - If station IS in discoveredStations: render full LOD tree as today (no change).
    - If station is NOT in discoveredStations: render ONLY an uncharted marker (dim StationBeacon with opacity 0.15, no label, no LOD tiers).
    - When ship enters within 200 units of an uncharted station (distance check in useFrame against flightState.position):
      a. Call `discoverStation(stationId)` to add to Set.
      b. Fire `window.dispatchEvent(new CustomEvent("observatory:station-discovered", { detail: { stationId } }))`.
      c. Start discovery animation phase.

    **Discovery animation (1.5s total) — ref-based, no re-renders:**
    Use a `discoveryPhaseRef` (type: `{ active: boolean; startTime: number }`) to track animation.
    When discovery triggers, set `discoveryPhaseRef.current = { active: true, startTime: clock.elapsedTime }`.

    In useFrame, compute `t = (clock.elapsedTime - startTime) / 1.5` (0 to 1):
    - Station geometry: render via a wrapper group with `meshRef` — set material opacity = lerp(0, 1, clamp(t / 1.0, 0, 1)) over 1.5s. Use `transparent: true` on a parent group scale or individual material opacity control.
    - Beacon PointLight intensity: lerp(0, 3, clamp(t / 0.67, 0, 1)) over 1.0s.
    - Docking ring scale: easeOutBack(clamp(t / 0.8, 0, 1)) — apply to docking ring group Y-scale from 0 to 1 over 1.2s. easeOutBack formula: `t * (2.70158 * t - 1.70158)` for overshoot.
    - Fresnel glow opacity: lerp(0, 0.6, clamp(t / 0.67, 0, 1)) over 1.0s.

    When t >= 1.0: set `discoveryPhaseRef.current.active = false` — animation complete, render normally.

    **Implementation approach for animation:**
    Instead of modifying child component internals, wrap the full LOD content in a `<group>` and use refs to control:
    - A parent group's visible flag (switch from uncharted beacon to animating LOD content).
    - Opacity via traversal: `groupRef.current.traverse((child) => { if (child.isMesh) child.material.opacity = ... })`.
    - Docking ring scale via a ref to the docking ring group.

    Use the pattern already established by NPC crew fade (stationProximityRef from Phase 25-04) — module-level refs for zero-subscription animation.

    **DISCOVERY_RADIUS constant:** `200` — triggers slightly beyond the 180-unit mid-LOD tier.
