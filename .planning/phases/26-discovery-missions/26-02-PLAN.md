    **1. Create MissionWaypointTrail.tsx:**

    A new R3F component that renders a glowing CatmullRom tube from the ship's current position to the active mission objective station.

    **Props:**
    ```typescript
    interface MissionWaypointTrailProps {
      mission: ObservatoryMissionLoopState | null;
      characterControllerEnabled: boolean;
    }
    ```

    **Visibility gate:** Only render when `mission !== null && mission.status === "in-progress" && characterControllerEnabled`.
    If gate fails, return `null`.

    **Tube geometry approach:**
    - Get the current objective via `getCurrentObservatoryMissionObjective(mission)`.
    - Look up target station position from `OBSERVATORY_STATION_POSITIONS[objective.stationId]`.
    - In `useFrame`, read ship position from `useObservatoryStore.getState().flightState.position`.
    - Build 3 control points for CatmullRomCurve3:
      - P0: ship position `[pos[0], pos[1], pos[2]]`
      - P1: midpoint `[(pos[0]+target[0])/2, (pos[1]+target[1])/2 + 10, (pos[2]+target[2])/2]` — Y+10 lift for gentle arc
      - P2: target station position `[target[0], target[1], target[2]]`
    - Create `CatmullRomCurve3` from these 3 points.
    - Generate `TubeGeometry(curve, 64, 0.2, 6, false)` — 64 segments, radius 0.2, 6 radial segments (per CONTEXT.md spec).

    **Performance pattern for ship-end updates:**
    - Use `useRef` for the tube mesh.
    - Use pre-allocated `THREE.Vector3` objects at module level (zero GC in hot path).
    - In `useFrame`, rebuild the curve and update geometry only when ship has moved > 2 units since last update (distance threshold to avoid per-frame geometry recreation). Use a `lastShipPosRef` to track last rebuild position.
    - Alternatively, use a simpler approach: re-create geometry every 4th frame (skip 3 out of 4 frames) to amortize cost.

    **Material:**
    - Emissive green `#44ff88` (per CONTEXT.md — distinct from blue `#4488ff` space lanes).
    - `MeshBasicMaterial` with `toneMapped={false}`, `transparent: true`, `blending: THREE.AdditiveBlending`, `depthWrite: false`.
    - Set material `opacity` based on distance to target:
      - If distance > 60 units: opacity = 0.6 (full glow).
      - If distance 0-60 units: opacity = `clamp((distance - 10) / 50, 0, 0.6)` — fades to 0 as ship approaches dock zone.

    **Cleanup:** Dispose geometry in useEffect cleanup or when objective changes.

    **2. Mount in ObservatoryWorldCanvas.tsx:**
    Add `<MissionWaypointTrail mission={mission} characterControllerEnabled={characterControllerEnabled} />` inside the scene tree. Place it after space lanes, before station LOD wrappers. Import the component at the top of the file.

    Find where `mission` and `characterControllerEnabled` are available in the component — they should already be props or derived from store. If `mission` is read from store inside ObservatoryWorldCanvas, use the same pattern. Pass them as props to MissionWaypointTrail.
