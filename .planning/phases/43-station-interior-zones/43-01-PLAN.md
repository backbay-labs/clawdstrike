Create `apps/workbench/src/features/observatory/components/world-canvas/StationInteriorScene.tsx`.

This R3F component renders a complete station interior when the analyst is inside a station.

**Props interface:**
```typescript
export interface StationInteriorSceneProps {
  stationId: HuntStationId;
  stationWorldPosition: [number, number, number];
  onTriggerHeroProp?: (prop: ObservatoryHeroPropRecipe, meta: MissionInteractionSource) => void;
  missionTargetAssetId: ObservatoryHeroPropRecipe["assetId"] | null;
  playerInteractableAssetId: ObservatoryHeroPropRecipe["assetId"] | null;
}
```

**Implementation:**

1. Look up `STATION_INTERIOR_CONFIGS[stationId]` for the interior definition.

2. Render the room as a `<group>` positioned at `stationWorldPosition` (same world position as the exterior station — the camera push handles the transition, not repositioning):

   **Floor:** `<mesh rotation={[-Math.PI/2, 0, 0]} position={[0, 0, 0]}>` with `<planeGeometry args={[20, 20]} />` and `<meshStandardMaterial color={config.wallColor} metalness={0.3} roughness={0.8} />`

   **Ceiling:** `<mesh rotation={[Math.PI/2, 0, 0]} position={[0, 8, 0]}>` with same plane geometry, slightly darker material.

   **4 Walls:** Use `<mesh>` with `<planeGeometry args={[20, 8]} />` positioned at the 4 cardinal sides of the room:
   - Back wall: position=[0, 4, -10], rotation=[0, 0, 0]
   - Front wall: position=[0, 4, 10], rotation=[0, Math.PI, 0]
   - Left wall: position=[-10, 4, 0], rotation=[0, Math.PI/2, 0]
   - Right wall: position=[10, 4, 0], rotation=[0, -Math.PI/2, 0]

   Walls use a two-tone approach: base color from `config.wallColor`, plus a subtle accent stripe mesh (thin box) at eye level using `config.accentColor` with emissiveIntensity 0.4.

3. **Interior Lighting:**
   - `<pointLight position={[0, 6, 0]} intensity={config.lightIntensity} color={config.accentColor} distance={25} decay={2} />`
   - `<ambientLight intensity={0.3} />` — slight ambient bump so shadows aren't pitch black

4. **Station Props:** Map over `config.props` and render each as the corresponding Three.js primitive:
   ```tsx
   {config.props.map((prop, i) => (
     <mesh key={`prop:${i}`} position={prop.position} rotation={prop.rotation ?? [0,0,0]}>
       {prop.type === "box" && <boxGeometry args={prop.args as [number, number, number]} />}
       {prop.type === "cylinder" && <cylinderGeometry args={prop.args as [number, number, number, number]} />}
       {prop.type === "torus" && <torusGeometry args={prop.args as [number, number, number, number]} />}
       {prop.type === "cone" && <coneGeometry args={prop.args as [number, number, number]} />}
       <meshStandardMaterial
         color={prop.color}
         emissive={prop.emissive ?? prop.color}
         emissiveIntensity={prop.emissiveIntensity ?? 0.2}
         metalness={0.5}
         roughness={0.4}
         toneMapped={false}
       />
     </mesh>
   ))}
   ```

5. **Interior NPCs:** Render 3 NPCs using drei `<Instances>` + `<Instance>` (same pattern as exterior `npcCrew.tsx`). Each NPC is a capsule geometry at the config position. Apply idle bobbing animation in `useFrame`: `position.y = baseY + Math.sin(clock.elapsedTime * 1.5 + i) * 0.06` (same sin(time) pattern as established in npcCrew.tsx but simpler — no patrol, just idle bobbing in place). Use `config.accentColor` for NPC material color.

6. **Hero Prop Interaction Zone:** Render a subtle glowing marker at `config.heroPropPosition` — a small emissive sphere (radius 0.3) with the prop's glowColor from `OBSERVATORY_HERO_PROP_ASSETS[config.heroPropAssetId].glowColor`. When clicked (`onClick`), call `onTriggerHeroProp` with the appropriate `ObservatoryHeroPropRecipe` and `{ source: "interior-click" }` meta. Add a `missionTarget` pulse effect (scale oscillation via useFrame) when `missionTargetAssetId === config.heroPropAssetId`.

Import types from: `../../world/types` (HuntStationId), `../../world/propAssets` (ObservatoryHeroPropAssetId, OBSERVATORY_HERO_PROP_ASSETS), `../../world/station-interior-config` (STATION_INTERIOR_CONFIGS, StationInteriorConfig), `../flow-runtime/grounding` (MissionInteractionSource), `../../world/deriveObservatoryWorld` (ObservatoryHeroPropRecipe).
