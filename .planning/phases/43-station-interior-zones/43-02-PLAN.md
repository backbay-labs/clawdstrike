**Part A: Create `useInteriorCameraTransition.ts`**

Create `apps/workbench/src/features/observatory/components/world-canvas/useInteriorCameraTransition.ts`.

This hook manages the smooth camera transition between exterior and interior views. It runs inside the R3F Canvas (uses `useFrame` and `useThree`).

```typescript
import { useFrame, useThree } from "@react-three/fiber";
import { useRef, useEffect } from "react";
import * as THREE from "three";
import type { ObservatoryInteriorState } from "../../types";

interface InteriorCameraTransitionOptions {
  interiorState: ObservatoryInteriorState;
  targetPosition: [number, number, number] | null; // station world position
  controlsRef: React.RefObject<THREE.EventDispatcher | null>;
  onTransitionComplete: (phase: "inside" | null) => void;
}

const TRANSITION_DURATION = 1.2; // seconds per CONTEXT.md
const INTERIOR_FOV = 50;
const EXTERIOR_FOV = 60;
const INTERIOR_NEAR = 0.02; // INTR-06 z-fighting prevention per CONTEXT.md
const EXTERIOR_NEAR = 0.1;
// Interior camera: center of room offset slightly back for orbit perspective
const INTERIOR_CAMERA_OFFSET = new THREE.Vector3(0, 4, 8);
// Constrained orbit limits inside room
const INTERIOR_MIN_DISTANCE = 3;
const INTERIOR_MAX_DISTANCE = 12;
const INTERIOR_MIN_POLAR = Math.PI * 0.15; // can't look straight down
const INTERIOR_MAX_POLAR = Math.PI * 0.75; // can't look straight up

export function useInteriorCameraTransition({
  interiorState,
  targetPosition,
  controlsRef,
  onTransitionComplete,
}: InteriorCameraTransitionOptions) {
  // ...implementation
}
```

**Implementation details:**

1. Track transition progress with `progressRef = useRef(0)` and `previousPhaseRef = useRef<string | null>(null)`.

2. Store the exterior camera state on entry: `exteriorCameraRef = useRef<{ position: THREE.Vector3; target: THREE.Vector3; fov: number; near: number } | null>(null)`.

3. When `interiorState.transitionPhase` changes to `"entering"`:
   - Capture current camera position, controls target, fov, and near plane into `exteriorCameraRef`
   - Set progressRef to 0
   - Compute interior target position: `new THREE.Vector3(targetPosition[0], targetPosition[1] + 4, targetPosition[2])` (room center at y=4 which is half of 8-unit room height)
   - Compute interior camera position: target + INTERIOR_CAMERA_OFFSET

4. In `useFrame((state, delta))`:
   - If `transitionPhase === "entering"`: increment progressRef by `delta / TRANSITION_DURATION`. Use quadratic ease-out: `t = 1 - (1 - progress) * (1 - progress)` per CONTEXT.md decision.
     - Lerp camera.position from exterior to interior camera position using `t`
     - Lerp controls.target from exterior target to interior target using `t`
     - Lerp camera.fov from EXTERIOR_FOV to INTERIOR_FOV using `t` and call `camera.updateProjectionMatrix()`
     - Set camera.near to lerp(EXTERIOR_NEAR, INTERIOR_NEAR, t) and `camera.updateProjectionMatrix()`
     - When progress >= 1.0: call `onTransitionComplete("inside")`, update OrbitControls constraints (minDistance, maxDistance, minPolarAngle, maxPolarAngle), set enableRotate=true, enablePan=false.

   - If `transitionPhase === "exiting"`: similar but reversed — lerp from current to stored exterior position. When complete, call `onTransitionComplete(null)` and restore OrbitControls to exterior constraints (enableRotate=false per existing config).

   - If `transitionPhase === "inside"`: no lerp needed, camera is stationary until user orbits

5. **OrbitControls constraint manipulation:** Access via `controlsRef.current as unknown as OrbitControls` (same pattern used in ObservatoryWorldScene.tsx for camera-focus event). Set `minDistance`, `maxDistance`, `minPolarAngle`, `maxPolarAngle` properties directly.

6. **Cleanup:** useEffect on interiorState changes — when `interiorState.active === false`, restore exterior constraints.

Export `useInteriorCameraTransition`.
