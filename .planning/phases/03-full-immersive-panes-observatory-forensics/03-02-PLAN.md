  <action>
    Extend ObservatoryTab.tsx with probe state:

    1. Add useState for probeState: `const [probeState, setProbeState] = useState<ObservatoryProbeState>(() => createInitialObservatoryProbeState())`
    2. Add useState for frameloop: `const [frameloop, setFrameloop] = useState<"demand" | "always">("demand")`
    3. Add useState for mode: `const [mode, setMode] = useState<"atlas" | "flow">("atlas")` (if not already in 03-01)
    4. Add dispatchProbe callback:
       ```typescript
       const dispatchProbe = useCallback(() => {
         const now = performance.now();
         setProbeState((prev) => {
           const resolved = advanceObservatoryProbeState(prev, now);
           if (resolved.status !== "ready") return prev;
           const targetId = sceneState?.stations[0]?.id ?? "signal";
           const next = dispatchObservatoryProbe(resolved, targetId as HuntStationId, now);
           setFrameloop("always");
           return next;
         });
       }, [sceneState]);
       ```
    5. Add useEffect to listen for window event "observatory:probe":
       ```typescript
       useEffect(() => {
         const handler = () => dispatchProbe();
         window.addEventListener("observatory:probe", handler);
         return () => window.removeEventListener("observatory:probe", handler);
       }, [dispatchProbe]);
       ```
    6. Add useEffect to revert frameloop when probe exits "active":
       ```typescript
       useEffect(() => {
         if (probeState.status !== "active") {
           setFrameloop("demand");
         }
       }, [probeState.status]);
       ```
    7. Pass frameloop, probeState, mode, setMode, characterControllerEnabled to ObservatoryWorldCanvas as props.
    8. Pass probeState and dispatchProbe to ObservatoryProbeHud (will be created in Task 2).

    NOTE on pitfall 2 (RESEARCH.md): The frameloop switching is the critical fix. Without it, the probe ring animation freezes because demand frameloop only renders on explicit invalidate() calls. Switching to "always" during the 5200ms active window keeps the ring expansion smooth.
