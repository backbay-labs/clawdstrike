       **Lane tube geometry (SPC-05):**
       - Import `OBSERVATORY_STATION_POSITIONS`, `buildLanePoints` from `observatory-world-template.ts`
       - Define lane pairs inline: `[["signal","targets"],["targets","run"],["run","receipts"],["receipts","case-notes"]]`
       - For each lane pair, create a CatmullRomCurve3 from the station positions. Use `buildLanePoints(fromPos, toPos, "flow")` to get the 25 interpolated points with Y-lift midpoint, then construct `new THREE.CatmullRomCurve3(points.map(p => new THREE.Vector3(p[0], p[1], p[2])))`
       - Create TubeGeometry: `new THREE.TubeGeometry(curve, 64, 0.3, 8, false)` — thin tube, 64 segments for smooth curve
       - Material: `new THREE.MeshBasicMaterial({ color: "#4488ff", transparent: true, opacity: 0.7, toneMapped: false })` — the toneMapped:false ensures it glows through bloom. Also set `side: THREE.DoubleSide` for visibility from all angles.
       - For animated dash-offset energy flow: Use THREE.LineDashedMaterial instead of MeshBasicMaterial on a separate Line3D, OR better approach: use a custom ShaderMaterial on the tube with a scrolling alpha pattern. Simplest approach per CONTEXT.md: use `MeshBasicMaterial` with `dashSize=2, gapSize=4` — but MeshBasicMaterial does not support dash. Instead:
         - Use a ShaderMaterial on the TubeGeometry with a simple vertex/fragment shader that creates a dashed pattern based on UV.x and a `dashOffset` uniform animated via useFrame
         - Vertex shader: pass through UV; Fragment shader: `float pattern = step(0.5, fract(vUv.x * 8.0 + dashOffset)); gl_FragColor = vec4(color, pattern * 0.7);` — this creates 8 dashes along the tube length, scrolling with dashOffset
         - Animate dashOffset: `materialRef.current.uniforms.dashOffset.value += delta * 3;` in useFrame (speed ~3 units/s per CONTEXT.md)
         - Set `transparent: true`, `depthWrite: false`, `toneMapped: false`, `blending: THREE.AdditiveBlending` for glow
       - Pre-compute all tube geometries in useMemo (one per lane pair = 4 total). Store as array of `{curve, geometry, fromId, toId}`.
       - Render each lane as a `<mesh geometry={geom}><shaderMaterial ... /></mesh>`.

       - Emit from the VFXEmitter with poolName="lane-particle-stream".
       - Particle lifetime: 2s. Color: accent blue "#4488ff" with slight variation. Size: 0.15-0.3.
       - Use a ref to track emission progress per lane. Emit ~75 particles/s per lane (= 150 particles at 2s lifetime).
