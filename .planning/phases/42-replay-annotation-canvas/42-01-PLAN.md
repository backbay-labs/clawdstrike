    Create `ReplayAnnotationLayer.tsx` as a new R3F scene layer component.

    **Props interface `ReplayAnnotationLayerProps`:**
    - `annotationPins: ObservatoryAnnotationPin[]` — current pins from store
    - `replayEnabled: boolean` — gates whether clicking drops a pin (only during replay)
    - `replayFrameIndex: number` — current replay frame to stamp on new pins
    - `replayFrameMs: number | null` — current replay timestamp
    - `spiritAccentColor: string | null` — pin color when spirit bound, fallback `#00d4ff`
    - `onDropPin: (worldPosition: [number, number, number]) => void` — callback when ground plane clicked

    **Pin visual (per CONTEXT.md locked decisions):**
    - Vertical diamond = two `ConeGeometry(0.25, 0.5, 6)` meshes, second rotated `Math.PI` on X axis and offset -0.5 on Y, grouped together
    - `MeshStandardMaterial` with `emissive` set to pin color (spiritAccentColor or `#00d4ff`), `emissiveIntensity: 0.6`
    - Fixed scale `[0.8, 0.8, 0.8]` on the group
    - Position at pin.worldPosition

    **Label (drei Text):**
    - drei `<Text>` component positioned 1.2 units above pin Y
    - `fontSize={0.35}`, `maxWidth={4}`, `anchorX="center"`, `anchorY="bottom"`
    - `color="white"`, `outlineWidth={0.02}`, `outlineColor="#000"`
    - Shows `pin.note` if non-empty, otherwise shows `"Pin"` as fallback
    - `depthTest={false}` so labels are always readable

    **Click-to-drop ground plane:**
    - Invisible `<mesh>` with `PlaneGeometry(200, 200)` rotated -PI/2 on X to lie flat at Y=0
    - `visible={false}`, `material={new MeshBasicMaterial({ visible: false, side: DoubleSide })}`
    - `onPointerDown` handler (NOT onClick — avoids conflict with orbit controls):
      - Only fires when `replayEnabled === true`
      - Reads `event.point` from the R3F intersection
      - Calls `onDropPin([event.point.x, event.point.y, event.point.z])`
      - Calls `event.stopPropagation()` to prevent orbit controls from consuming the event

    **Edit overlay (drei Html):**
    - Local state `editingPinId: string | null` tracks which pin is being edited
    - Clicking a pin mesh sets `editingPinId = pin.id` (if replay enabled)
    - When `editingPinId` matches a pin, render drei `<Html transform sprite distanceFactor={60}>` at that pin's position + 2 units Y offset
    - Html content: a glassmorphism-styled div with:
      - `background: var(--hud-bg)`, `border: var(--hud-border)`, `backdropFilter: var(--hud-blur)`, `borderRadius: 8px`, `padding: 8px`
      - `<input>` element: `type="text"`, autofocus, `defaultValue={pin.note}`, `placeholder="Add note..."`,
        `fontSize: 12px`, `color: var(--hud-text)`, `background: rgba(255,255,255,0.06)`, `border: none`, `borderRadius: 4px`, `padding: 4px 8px`, `width: 160px`, `outline: none`
      - On Enter keydown or onBlur: read input value, call `useObservatoryStore.getState().actions.removeAnnotationPin(pin.id)` then `useObservatoryStore.getState().actions.addAnnotationPin({ ...pin, note: inputValue })` (replace pattern since store has no update action), set `editingPinId = null`
      - Delete button: small `x` button, `fontSize: 10px`, `color: var(--hud-text-muted)`, onClick calls `useObservatoryStore.getState().actions.removeAnnotationPin(pin.id)`, sets `editingPinId = null`
    - Clicking outside (ground plane click or another pin click) sets `editingPinId = null`

    **onDropPin callback (implemented in the parent, but the layer calls it):**
    The layer itself calls `onDropPin` with the world position. The parent (ObservatoryWorldCanvas) will construct the full `ObservatoryAnnotationPin` and call `addAnnotationPin`.

    Create test file `replay-annotation-layer.test.tsx` with the 5 tests described in the behavior block. Use vitest + @testing-library/react. Mock the Three.js geometries and drei components as needed. Test the component's rendering and basic state logic.
