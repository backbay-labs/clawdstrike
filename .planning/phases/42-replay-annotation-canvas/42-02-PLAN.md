    Actually, a cleaner approach: Add a `useEffect` in the `ObservatoryWorldScene` component itself (in `ObservatoryWorldScene.tsx`) that listens for `observatory:camera-focus` events on `window`:

    In `ObservatoryWorldScene.tsx`, add after the existing `controlsRef` setup:
    ```typescript
    // ANNO-05: Camera focus on annotation pin — lerp orbit controls target to pin position
    useEffect(() => {
      function handleCameraFocus(e: Event) {
        const detail = (e as CustomEvent).detail as { target: [number, number, number]; duration: number } | undefined;
        if (!detail?.target || !controlsRef.current) return;
        const controls = controlsRef.current as unknown as { target: THREE.Vector3 };
        if (!controls.target) return;
        controls.target.set(detail.target[0], detail.target[1], detail.target[2]);
      }
      window.addEventListener("observatory:camera-focus", handleCameraFocus);
      return () => window.removeEventListener("observatory:camera-focus", handleCameraFocus);
    }, []);
    ```

    Note: This is an immediate snap (not a smooth lerp) for simplicity. The 0.8s smooth feel comes from OrbitControls' built-in `dampingFactor` which is already set to `world.camera.dampingFactor`. When we set `controls.target` directly, the damping smooths the transition naturally. This matches the existing station focus convention.
