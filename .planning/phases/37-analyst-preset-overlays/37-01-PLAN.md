    Pure helper `getEvidenceStationIds(traces: ObservatoryGhostTrace[]): HuntStationId[]`:
    - Returns unique stationIds from traces where `sourceKind === "receipt"` (receipts are the evidence)
    - Empty traces → []
    - Traces with sourceKind="finding" only → []
    - Two receipt traces at same station → deduplicated to one entry
    - Order: insertion order of first occurrence

    Pure helper `groupReceiptTracesByStation(traces: ObservatoryGhostTrace[]): Map<HuntStationId, ObservatoryGhostTrace[]>`:
    - Returns Map of stationId → traces filtered to sourceKind="receipt"
    - Only includes stations that have at least one receipt trace
    - Empty input → empty Map

    Pure helper `verdictColor(trace: ObservatoryGhostTrace): string`:
    - trace.headline includes "Denied" (case-insensitive) → "#ef4444" (red DENY)
    - trace.detail includes "audit" (case-insensitive) OR trace.score < 0 → "#f59e0b" (amber AUDIT)
    - Otherwise → "#22c55e" (green ALLOW)

    R3F `EvidencePresetOverlay({ traces })`:
    - Accepts `traces: ObservatoryGhostTrace[]`
    - For each stationId from getEvidenceStationIds(traces): renders a TorusGeometry(innerRadius=1.8, tube=0.06, radialSegments=8, tubularSegments=64) at station position y+1.0. Material: color="#d4a93a", opacity=0.7, toneMapped=false, AdditiveBlending, transparent, depthWrite=false
    - useFrame rotates the torus group: `group.rotation.y += delta * 0.4` (slow spin)
    - Returns null when getEvidenceStationIds(traces).length === 0

    R3F `ReceiptsPresetOverlay({ traces })`:
    - Accepts `traces: ObservatoryGhostTrace[]`
    - For each station in groupReceiptTracesByStation(traces): renders up to 3 badge meshes (BoxGeometry 0.28, 0.28, 0.04) stacked vertically at station position y+[1.4, 1.9, 2.4]. Badge color from verdictColor(trace). Material: toneMapped=false, AdditiveBlending, transparent, depthWrite=false, opacity=0.8
    - useFrame: badges gently bob — `mesh.position.y = baseY + Math.sin(t * 1.1 + phase) * 0.12` (no state, mutate directly via ref)
    - Returns null when groupReceiptTracesByStation(traces).size === 0
  </behavior>
