**Gap 2 — Autopilot Ref Bridge: CLOSED**

Star chart click → `setAutopilotTarget(id)` → subscription fires → `autopilotRef.current` updated → `useFlightLoop` slerp + thrust executes. WASD cancels via `onAutopilotCancel` → `clearAutopilot()`.
